Show a test file.

Ordinary deletion is followed by a supported recovery demonstration.

## Scene 3 — Permanent deletion
Select file/folder.

Show:
- target preview
- storage profile
- dry-run
- explicit confirmation
- operation progress
- recovery test
- residual scan

Result:
- recovery not successful within supported test scope
- residual result

## Scene 4 — Controlled recoverable deletion
Delete another file using controlled recovery.

Show:
- original disappears
- encrypted recovery object exists
- unauthorized restore blocked
- authorized restore succeeds
- restored SHA-256 matches original

## Scene 5 — Certificate
Show signed evidence.

Verify certificate = valid.

Change evidence.

Verify certificate = invalid.

Judge takeaway:
Oblivion turns deletion into a measurable, testable and verifiable security operation.
