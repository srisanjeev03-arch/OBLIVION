# Benchmark Protocol

Measure:

## Erasure
- operation duration
- files/sec
- bytes/sec
- CPU
- memory
- failure rate

## Recovery
- baseline recovery success
- post-erasure recovery success
- recovery duration

## Residual scan
- scan duration
- artifacts found
- false positives
- false negatives on synthetic ground truth

## AI
- classification precision/recall
- latency
- provider/model
- token/compute cost where measurable

All benchmarks must use reproducible synthetic datasets.
