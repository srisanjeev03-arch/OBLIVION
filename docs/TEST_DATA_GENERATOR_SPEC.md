# Test Data Generator

Generate synthetic fixtures for demos/tests.

## Dataset types

- customer CSV
- employee records
- financial-like records
- confidential documents
- temporary files
- duplicate/near-duplicate files
- binary fixtures
- nested directory trees

## Requirements

All data must be synthetic.

Include known ground truth:
- expected sensitivity
- original SHA-256
- expected file relationships
- expected deletion mode
- expected recovery outcome

## Demo dataset

Create a small dataset that visibly contains:
- names
- emails
- phone numbers
- addresses
- synthetic account identifiers

Never use real personal data.
